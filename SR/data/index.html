Import validates your file, saves and reads back a complete backup, then asks you to confirm once. Stop playback first; completed Android steps are saved automatically before backup.

The backup picker suggests the incoming file’s location when supported. Check the destination: choose the same OneDrive folder, or Downloads. A selected file does not grant permission to write to its parent folder. SR never chooses a different folder silently.

On desktop use Chrome on HTTPS or localhost and allow the file picker. On Android use the system file picker. Wait for OneDrive synchronization before using files on another device. Imports replace; they do not merge. File limit: 32 MiB.
